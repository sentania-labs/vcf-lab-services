Backup service

The SFTP backup service writes to the separate mounted backup path. It never shares the depot volume.

While the backup service is enabled it re-reads these two settings every few seconds, so both take effect at once: turning the service off ends current SFTP sessions, and a UID:GID change re-owns stored backup content.
